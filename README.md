# Sistema de Control de Laboratorios de Cómputo (Web) - Proyecto C

Aplicación Web SPA desarrollada con **React JS + Vite** para la gestión y asignación de equipos de cómputo y periféricos en los laboratorios de la Universidad Tecnológica El Retoño (UTR).

## Variables de Entorno
Copia el archivo `.env.example` a `.env` y configura las credenciales correspondientes:
- `VITE_API_URL`: URL base de la API RESTful.
- `VITE_API_APP_TOKEN`: Token de autenticación de la aplicación cliente (`x-api-token`).

## Instalación y Ejecución Local
```bash
npm install
npm run dev
